# Opcode.nvim

A clean, low-glare dark colorscheme for Neovim.

## Features

- Dark `#181818` background
- Soft, low-contrast foreground
- Modern Tree-sitter highlighting
- LSP support
- Popular plugin support

## Installation

### Packer

```lua
use("SOHAN-MONIES/opcode.nvim")
```

## Development

```bash
git clone https://github.com/SOHAN-MONIES/opcode.nvim
cd opcode.nvim
```
